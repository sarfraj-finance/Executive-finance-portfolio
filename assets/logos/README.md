# assets/logos/

Reserved for institution/employer logos (ACCA, SOCPA, Oxford Brookes, Amity
University, CFI) if you want to display them on the Qualifications or
Education pages instead of plain text.

**Before adding any logo here:** check that usage is permitted under each
organization's brand guidelines — most professional bodies allow members to
reference their credential but restrict logo use without permission. When in
doubt, use text-only credential mentions (which is what the site currently
does) rather than an unauthorized logo.
