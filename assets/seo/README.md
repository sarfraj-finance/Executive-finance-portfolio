# assets/seo/

Reserved for SEO-related assets beyond the root-level `sitemap.xml` and
`robots.txt` — for example:

- Per-page social preview images, if you want a different Open Graph image
  for individual pages instead of the single shared `og-image.jpg`
- A Google Search Console verification file (e.g. `google1234567890.html`),
  once you register the domain
- Structured-data snippets for specific pages, if you expand beyond the
  single Person schema currently embedded in each page's `<head>`

Nothing is required here for the site to function — this folder exists so
future SEO assets have an obvious home instead of getting mixed into
`assets/images/`.
