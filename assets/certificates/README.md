# assets/certificates/

Six redacted certificates are in place, prepared from the real source documents with membership numbers, QR codes, sensitive identifiers, and unnecessary fine print removed where applicable:

- ACCA_Membership_Redacted.pdf
- ACCA_AAA_Prize_Redacted.pdf
- SOCPA_Associate_Redacted.pdf
- Oxford_Brookes_Degree_Redacted.pdf
- JRN_Degree_Redacted.pdf
- MCom_Provisional_Certificate_Redacted.pdf

If you add any certificate here yourself:

- Black out or crop membership or registration numbers
- Remove QR codes
- Remove national ID, passport, or Iqama references
- Remove personal address details if visible
- Keep only information needed to verify the qualification

A matching thumbnail in `thumbnails/` using the same filename plus `_thumb.jpg` will display an image preview instead of a text-only link.

Examples:

- `JRN_Degree_Redacted_thumb.jpg`
- `MCom_Provisional_Certificate_Redacted_thumb.jpg`

See `js/credentials.js` for the file-detection and preview logic.
