CHANGELOG — About Page Navigation Fix
======================================

ROOT CAUSE
----------
The About link was already correctly enabled in the working index.html
during the previous session (About & Philosophy pointing to about.html,
no aria-disabled, no Coming Soon badge). However, that delivery only
returned about.html / about.css / about.js as individual files — the
updated index.html was never re-packaged and handed over. The index.html
actually in use still had the OLD, disabled version of the link:

    <a href="about.html" aria-disabled="true">
      About & Philosophy <span class="coming-soon-badge">Coming soon</span>
    </a>

That is why clicking the nav item did nothing: navigation.js correctly
blocks any element with aria-disabled="true", and the old file still had
that attribute. This was a delivery/packaging gap, not a design or logic
bug in the navigation system itself.
